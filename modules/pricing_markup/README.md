# Модуль `pricing_markup` — націнка по групах клієнтів

Перевертає логіку ціноутворення: замість «ціна мінус знижка» — **«базова ціна плюс націнка групи»**.

## Правило

- Ціна в картці товару — **базова** (закупка/собівартість). Покупець її не бачить.
- Клієнт бачить `базова + % націнки своєї групи`.
- Неавторизований покупець і клієнт без групи → група, позначена **`is_default`** («стандартна»).
- Немає стандартної групи або модуль вимкнено → ціна лишається базовою (націнка 0 %).

## Де керувати

**Продажі → «Групи клієнтів»** — той самий звичний розділ, у якому вже жили групи.
У картці групи: «Відсоток націнки» з живим прикладом ціни та перемикач «Стандартна група»
(для неавторизованих). Окремої сторінки НЕМАЄ — свідомо, щоб не тримати керування
групами у двох місцях.

## Як під'єднано до ядра

Ядро **не знає** про націнку. `Product::priceViewForUser()` (єдина точка ціноутворення)
прогоняє базову ціну через фільтр:

```php
$base = Hooks::filter('pricing.base_price', $base, $user);
```

Модуль підписується на цей фільтр у `PricingMarkupServiceProvider::boot()`.
Вимкнули модуль → фільтра немає → ціни стають базовими без жодних правок коду.

Націнка застосовується **до** решти логіки й стає «звичайною» ціною для клієнта.
Тому знижки (`discount_percentage`) і фіксовані гуртові ціни працюють як раніше —
відштовхуються від націненої ціни, а перекреслена «стара ціна» лишається коректною.

## Файли

| Файл | Роль |
|---|---|
| `src/Services/MarkupPricing.php` | резолв групи (гість → стандартна), розрахунок націнки |
| `src/PricingMarkupServiceProvider.php` | фільтр `pricing.base_price`, гарантія «стандартна лише одна» |
| `database/migrations/*_add_markup_percentage_to_customer_groups.php` | колонка `markup_percentage` |

Колонка `discount_percentage` **не видаляється** — лишається для знижкових сценаріїв
і як шлях відкату.

## Вимоги

Модуль `wholesale` (він володіє таблицею `customer_groups` і моделлю `CustomerGroup`).

## Вимкнути

`MODULE_PRICING_MARKUP=false` в `.env` або перемикач у Розширеннях. Ціни повернуться до базових.
